# Final submission

This folder contains the code for the AAI-540 Group 4 final project. See the [top-level README](../README.md) for the overview, results, architecture, and reproduction steps.

- `AAI540_Turbofan_RUL_AWS_SageMaker.ipynb`: the complete system (Modules 2-7). Open it from this folder.
- `pipeline_scripts/`: `validate_data.py` and `evaluate.py`, used by the SageMaker Pipeline steps.
- `cloudwatch_monitoring_setup.py`: CloudWatch dashboard setup, imported by the notebook (must stay beside it).
- `data/README.md`: S3 data layout.
- `requirements.txt`: Python dependencies.
